# CRM Enterprise - Frontend

Giao diện người dùng hệ thống CRM Enterprise xây dựng bằng React 19 + Vite.

## Cài đặt và Khởi chạy

1. Cài đặt thư viện:
```bash
npm install
```

2. Khởi chạy môi trường phát triển (Dev server):
```bash
npm run dev
```
Mặc định ứng dụng chạy tại: `http://localhost:3000`

3. Đóng gói bản Production:
```bash
npm run build
```

## Các module chính:
- **Tổng quan & Bàn làm việc**: Dashboard, thống kê kinh doanh, KPI.
- **Quản lý khách hàng**: Khách hàng 360°, nhập Excel, phát hiện gộp trùng.
- **Lead & Marketing**: Thu thập Lead, chiến dịch Marketing, biểu mẫu nhúng, chấm điểm Lead.
- **Quản lý bán hàng**: Phễu cơ hội (Kanban), dự báo doanh số, timeline hoạt động, công việc & lịch.
- **Cấu hình & Quản trị**: Danh mục, bảng giá, phân quyền vai trò.
