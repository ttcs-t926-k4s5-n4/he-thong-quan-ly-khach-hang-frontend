# Phần 1 — Nhận/từ chối Lead & SLA

```bash
npm install
npm run test:logic
npm run dev
```

SLA demo là 24 giờ. Nhận lead chuyển sang “Đang chăm sóc”; từ chối phải nhập lý do và trả về “Chờ phân bổ”; ghi nhận liên hệ ngăn cờ SLA. Nút báo trưởng nhóm mô phỏng việc tạo thông báo trên giao diện, chưa gửi thông báo thật.
