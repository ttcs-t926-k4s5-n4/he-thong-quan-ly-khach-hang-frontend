# Phần 3 — Danh sách Lead, bộ lọc và bộ lọc lưu sẵn

```bash
npm install
npm run test:logic
npm run dev
```

Bộ lọc gồm từ khóa, trạng thái, nguồn, mức độ nóng/ấm/lạnh, người phụ trách, khoảng thời gian và chỉ hiển thị lead quá SLA. Bạn có thể lưu bộ lọc bằng tên riêng, áp dụng/xóa bộ lọc đã lưu và xuất kết quả ra CSV.
